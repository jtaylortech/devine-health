# Devine Health — Brand Tokens

Derived from the business card. Cleaned up for web (WCAG AA contrast on white and navy).

## Core palette

| Token | Hex | Use |
|-------|-----|-----|
| `--navy` | `#0E3A5F` | Primary brand color, headings, footer, nav |
| `--navy-deep` | `#0B2E4A` | Hero overlay, deep sections |
| `--gold` | `#E0A82E` | Primary accent, buttons, highlights |
| `--gold-light` | `#F0C15A` | Hover states, gradients |
| `--teal` | `#3FA9C4` | Secondary accent (from logo hands, light) |
| `--teal-dark` | `#1C6E86` | Secondary accent (from logo hands, dark) |
| `--ink` | `#1A2733` | Body text on light backgrounds |
| `--slate` | `#5A6B7B` | Muted text, captions |
| `--cream` | `#F7FAFC` | Section background (soft, warm) |
| `--white` | `#FFFFFF` | Cards, base background |
| `--line` | `#E3EAF0` | Borders, dividers |

## Typography

- **Headings:** a refined serif to echo the "Devine" wordmark — `Cormorant Garamond` / `Playfair Display` (web), falling back to Georgia.
- **Body / UI:** a clean humanist sans — `Inter` / system stack — for readability and a modern, medical feel.
- **Wordmark "HEALTH":** letter-spaced uppercase (`letter-spacing: 0.35em`).

## Voice

Clean · Medical · Trustworthy · Warm. Lots of white space. Never cramped.
Tagline: **"Empowering Independence Through Compassionate Care."**
